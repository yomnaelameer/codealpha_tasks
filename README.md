## 📂 Projects

### 🔹 Task 1 – AI Language Translation Tool

A Streamlit-based language translation application that allows users to translate text between different languages using a translation API.

**Technologies:**

* Python
* Streamlit
* REST APIs
* HTTP Requests
* JSON
* API Integration

---

### 🔹 Task 2 – AI FAQ Chatbot

An AI-powered FAQ chatbot that uses Natural Language Processing techniques to find the most relevant answer to a user's question from a predefined FAQ dataset.

The project applies text preprocessing, **TF-IDF vectorization**, and **Cosine Similarity** to match user questions with the most relevant FAQ.

**Technologies:**

* Python
* Natural Language Processing (NLP)
* NLTK
* Pandas
* TF-IDF
* Cosine Similarity
* Streamlit

---

### 🔹 Task 3 – AI Object Detection and Tracking

A Computer Vision project for detecting and tracking objects in video using **YOLO11** and **OpenCV**.

The system detects objects, assigns tracking IDs, calculates center points, counts current and unique objects, monitors FPS, and detects people crossing a predefined line to calculate **IN / OUT counts**.

**Technologies:**

* Python
* YOLO11
* Ultralytics
* OpenCV
* Object Detection
* Object Tracking
* Computer Vision
